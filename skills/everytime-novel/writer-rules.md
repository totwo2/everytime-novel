# writer-rules.md - 正文写作规则(作者视角)

> 写手子代理读这个文件。目标:写出来就是人味,不需要二次改写。

---

## 核心铁律

1. **字数 ≥ 设定.md中用户指定的最少字数**(默认2400),最多不超过最少字数的150%
2. **第三人称叙述**,全文禁止"我"(对话中可保留)
3. **双换行短段落**,不写【本章完】
4. **身体感受描写 ≥ 4处/章**
5. **语气词 ≥ 1处/章**
6. **开头第一句必须是人物的具体动作或对话**,禁止用氛围描写、情绪独白、悬念钩子、时间流逝、静止状态开头
7. **结尾最后一段必须包含人物的具体动作**(走路/说话/拿东西/转头/按下按钮等),禁止用静止状态、氛围收尾、情绪留白、未规划的悬念钩子结尾
8. **破折号"——"完全禁止**，无例外，对话中断用省略号"……"替代
   （指标不变；执行方式见下方「事后清」——**写时不必逐句自查，写完批量清**）

---

## 写作前必读（仅当语言DNA存在）

若项目 `settings/本书语言DNA.md` 存在，**动笔前先读它**，再按它的硬性约束写本章：

| 读 | 用途 |
|---|---|
| L1 表层语言 | 对话占比、平均句长、标点习惯（这本书的呼吸感） |
| L2 章节结构 | 章首/章尾类型分布（本书习惯怎么开场、怎么收尾） |
| L3 叙事习惯 | 主角行为逻辑、冲突处理偏好、金手指节奏 |
| 硬性约束 | 对话占比 ±5%、平均句长 ±3 字等可验收项 |

另外从 `dna-corpus/` 挑 **3 章**与本章情境最接近的原文通读——DNA 整合文档是压缩结论，语感只在原文里。

**若本书体裁与 DNA 头部标注的体裁不同**（跨大类，如玄幻的 DNA 用在近代文上）：按 `dna-rules.md` 第二节做复用检查，**L3 叙事习惯不要直接照搬**——手感能带走，套路带不走。

**不存在则跳过本节**，按本文件通用规则写。
**冲突时**：本文件开头的核心铁律（字数下限、章首必须动作或对话、破折号零容忍）**不被 DNA 覆盖**；其余按"用户指令 > DNA > 通用规则"排序。

## 禁用词(零容忍)

写入prompt,逐词检查:

```
与此同时/从而/于是/因此/值得注意的是/综上所述/不言而喻/毋庸置疑/赋能/闭环/重塑/未来可期/意义重大/深刻剖析/系统性/应运而生/众所周知/发人深省/总而言之/璀璨/瑰丽/绚烂/心潮澎湃/热血沸腾/令人不安/令人窒息/非常震惊/令人震惊/令人惊叹/难以置信/顺滑/丝滑/首先/其次/值得一提的是/然后/最后/再次/而且/并且/因而/此外/不可或缺/由此可见/打造/引人注目/一气呵成/仿佛/宛如/骤然/缓缓/淡淡/如同/瞬间
```

**以上词无一例外,没有"特殊情况下可以用"的说法。**

**替换策略:**
- "最后" → "末尾" / "收尾" / 直接删除
- "然后" → "接着" / "这之后" / 逗号连接 / 直接删除
- "而且" → 删除,用逗号连接
- "仿佛/宛如/如同" → "像" / "好像" / 具体描写
- 其他 → 根据语境替换为具体描写

## 破折号禁令

**绝对禁止 `--`(U+2014 U+2014),完全无例外**

对话中断用省略号"......"替代

**替代方案:**
- 解释型 → 逗号
- 延续型 → 句号/逗号
- 语气型 → 删除

---

## 省略号格式

统一使用 `......`(中文省略号,U+2026 U+2026)

禁止:`......`(6点)、`...`(3点)、`······`(中点)

## 代词规则

- **角色名与性别以 `settings/设定.md` 为唯一真源**，从设定.md读取，禁止照抄任何示例名
- 男主 → 用"他"；女主 → 用"她"（性别以设定.md为准）
- **每句话确认代词指向正确**

## 冒号使用

- 对话引号内语气中断 → 用冒号 `:`
- 不单独成段

## 去AI味：写时管什么、事后清什么

**判据只有一条：事后修它要花多少成本。**

| 层 | 修它的成本 | 谁管 | 占用写手注意力？ |
|---|---|---|---|
| **语言层**（要重写句子） | 高——起手式、名词化、喻体、翻译腔改起来要重组句子 | **写时管** | ✅ 要，这是重心 |
| **符号层**（可批量替换） | 极低——破折号、省略号格式、标点统一，脚本一把清 | **事后清** | ❌ 不要 |
| **篇章层**（要统计视角） | 写时根本看不见 | **事后扫** | ❌ 想管也管不了 |

**所以写手的注意力只花在"事后改起来贵"的地方。** 符号类不配占用它——写的时候每写一句就去数有没有破折号，只会打断思路，而这件事事后一次批量处理就完了。

### 写时管（语言层，7 条）

（R1 禁用词单列在下一节，同属"写时管"）

1. **起手式禁用**：禁止「说白了」「说穿了」「先说结论」「众所周知」「值得注意的是」「不难看出」「总而言之」。要下判断就直接下。

2. **名词化禁用**：禁止「完成了对……的……」「实现了……的提升」「进行了……的优化」「作出了……的调整」。一律恢复动词。
   - ❌ 团队完成了对流程的优化 → ✅ 团队把流程改顺了

3. **理想化职业人格喻体禁用**：禁止「像/相当于 + 一位/一个 + 职业角色（导师/秘书/助手/顾问/审查员/实习生）」且带褒义修饰（智慧的、永不疲倦的、全能的）或后接「不仅……更……」。
   - ❌ 它像一位智慧的导师，不仅给结论，更给视角 → ✅ 它不只给结论，也讲看待问题的角度
   - **不禁用**：具体的人当喻体（「像一个老师傅」）——人类就这么写；修仙/系统流的器灵、系统精灵属于设定，不在禁令内

4. **翻译腔三种禁用**：
   - 过长前置定语：中心名词前修饰超过 15 字，或「的」连续两个以上 → 拆成两个分句
   - 「当……时」前置时间从句 → 删「当」「时」，从句直接作前一分句
   - 前置话题壳：「对于……来说/对……而言/就……而言/关于……/在……方面」→ 把对象放到主语位
   - **不禁用**：被动句、名词化长句本身、专业术语、修仙术语、公文固定表达

5. **顿号罗列过密（R5）禁用**：一个分句里不出现 3 个以上顿号、不连起 4 项以上并列。能概括就概括，必须列全时改变其中一项的句法。
   - **不禁用**：物品/菜名/清单的列举语境（网文正常叙事）

6. **序数词小标题（R10）禁用**：小标题不用「一、二、三」「第一、第二」通篇编号。**不禁用**：正文里的「首先……其次」（那是 R1 禁用词管的），Markdown 有序列表。

7. **空转句引出列表（R11）禁用**：不写"我见过的几种典型场景："这种只宣布"下面有列表"、去掉后信息不减的句子。要列就直接列，或把这句写成有内容的判断。

### 事后清（符号层，写的时候不用管）

以下**写手不必盯**，交给去AI味环节批量处理。写的时候尽管顺着思路写，不用为它们分心：

| 项 | 规则 | 处理方式 |
|---|---|---|
| 破折号 `——` | R2（零容忍） | 脚本扫出全部位置，逐处按语境替换（解释型→逗号、延续型→句号、语气型→删） |
| 省略号格式 | R14 | 非标准形式（`......` / `...` / `······`）统一为 `……` |
| 标点统一 | R14 | 中英文标点混用、引号不配对等 |

**注意**：符号类叫"批量清"不等于"一把梭替换"。破折号在不同语境要换成不同的标点（逗号/句号/删除），**脚本只负责定位，替换要逐处看语境**。

**写完后自检**：跑 `python3 scripts/check_ai_tone.py {本章路径}`，R1/R2 必须为零。
**这一步不是"返工"，是"验收"**——写对了就是空跑，几秒钟；报错了只改命中处，不做全文重写。

## 角色名字规范(单一真源 SSOT)

**⚠️ 角色名以设定.md为唯一真源,本文件不预填任何占位名。**

实战教训(v1.3.2前):skill模板预填"勋空"为男主名,但设定.md写"待命名",正文却用"陈卫国",三层打架导致50+处混用(P0)。

**铁律:**
1. 写手读设定.md获取真实角色名,不得用本模板里写死的名字
2. 若设定.md角色名缺失(如"待命名"),停下来报告main,**绝不自己编名**
3. 全文同一角色只用一个名字,禁止混用(如陈卫国/勋空并存)
4. 代词:男主=他,女主=她,以设定.md性别为准

**示例表(实战《七零年代苟道日常》配角,仅作格式参考,新书须替换为本书真实角色):**

| 角色 | 正式名 | 可用称呼 | 禁止 |
|------|--------|----------|------|
| 女主 | 林昭 | 林昭、她 | - |
| 姐姐 | 林玥 | 林玥、姐姐、她 | 勋璇(已废弃) |
| 白泽 | 沈砚 | 沈砚 | - |
| 百草 | 苏晴 | 苏晴 | - |
| 教官 | 陈烈 | 陈烈 | - |
| 引导官 | 赵衡 | 赵衡 | 周衡(不同角色) |
| 技术官 | 老周 | 老周 | - |

```
# 第XXX章:标题内容
```

- 必须有标题,不能缺失
- 标题不能重复(全书唯一)
- 不用破折号、不用英文标点

## 写完每章后:格式自检

写完每章后,执行以下检查(不需要单独的gate.py):

1. 禁用词扫描 → 发现即替换
2. 破折号扫描 → 替换为逗号/句号/冒号
3. 省略号统一 → 全部改为......
4. 代词检查 → 以 settings/设定.md 为准（男主=他，女主=她）
5. 字数检查 → ≥ 设定.md中用户指定的最少字数(默认2400)
6. 标题检查 → 格式正确,不重复

自检不通过的,自行修复后再输出。

## 物品规则
- **写手只管状态栏里的东西**：细纲【本章状态】栏里有什么就写什么，不用自己判断哪些物品需要追踪
- **有前后作用的物品才写入正文**：在哪里用、数量变化
- **一次性物品不用管**：肥皂、红糖等不写到状态栏的物品，不用追踪
