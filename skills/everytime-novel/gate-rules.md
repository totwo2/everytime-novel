# gate-rules.md — 格式检查规则（整合进写手子代理）

> 格式检查不再由单独的gate.py执行，而是整合进写手子代理的写作过程中。
> 写手写完每章后，自己做格式检查。

---

## 怎么整合进写手prompt

在writer子代理的prompt末尾，追加以下自检指令：

```
## 写完每章后：格式自检（必须执行）

写完每章后，执行以下检查，不通过的自行修复后再输出：
1. 禁用词扫描 → 发现即替换
2. 破折号扫描 → 全部替换（`——` 零容忍，含对话中断，改用省略号）
3. 省略号统一 → 全部改为……
4. 代词检查 → 以 settings/设定.md 的真实角色名为准
5. 字数检查 → ≥ 设定.md 中用户指定的最少字数（默认2400）
6. 标题检查 → 格式正确，不重复
7. 去AI味自检 → 跑 scripts/check_ai_tone.py，R1/R2 必须为 0
```

这段指令直接嵌入writer-rules.md的输出格式部分，不需要单独的gate.py。

---

## 写手自检清单（写完每章后执行）

### 1. 禁用词检查
**以 `writer-rules.md` 的「禁用词(零容忍)」表为准**（单一真源，不在此处重复维护，避免两处词表漂移）。

### 2. 破折号检查
- 叙事型 `——` → 逗号/句号
- 对话中断 `"你——"` → 省略号 `……`（`——` 零容忍，无例外）
- 对话语气中断 → 冒号

### 3. 省略号检查
统一为 `……`（中文省略号）

### 4. 代词检查
以 `settings/设定.md` 的真实角色名与性别为准（禁止照抄示例名；实战曾因模板预填名导致三层打架 P0）。

### 5. 字数检查
每章 ≥ `settings/设定.md` 中用户指定的最少字数（默认 2400 中文字）

### 6. 标题检查
格式：`# 第XXX章：标题`，不重复，不缺失

### 7. 段落检查
双换行分段，不写【本章完】

## 稽核子代理检查标准（内容层面）

稽核子代理读设定.md + 细纲 + 正文，检查：

| 检查项 | 对照源 | 说明 |
|--------|--------|------|
| 角色名是否在角色表里 | 设定.md | 防止凭空编角色 |
| 技能是否在技能库里 | 设定.md | 防止编造技能 |
| 伏笔是否按计划植入/回收 | 细纲 | 防止遗漏伏笔 |
| 角色行为是否符合人设 | 设定.md | 防止人设崩塌 |
| 世界观是否一致 | 设定.md | 防止设定矛盾 |
| 章节间有无重复/矛盾 | 正文 | 防止内容重复 |
| 代词是否正确 | 设定.md | 防止性别混乱 |
| 字数是否达标 | 设定.md | ≥ 用户指定下限（默认2400字/章） |
| 去AI味是否达标 | 脚本 | `scripts/check_ai_tone.py`，R1/R2 非零=P0 |

---

## Gate.py 退役说明

gate.py不再作为独立的检查步骤。其功能已拆分：
- **格式检查** → 整合进写手子代理（写完自检）
- **内容检查** → 整合进稽核子代理（读设定+细纲+正文）
