# format-rules.md — 格式标准

> 通用参考。所有子代理和main都应遵守。

---

## 省略号

**统一为 `……`（中文省略号，U+2026 × 2）**

| 格式 | 状态 | 替换为 |
|------|------|--------|
| `……` | ✅ 正确 | — |
| `......`（6点） | ❌ 禁止 | `……` |
| `...`（3点） | ❌ 禁止 | `……` |
| `······`（中点） | ❌ 禁止 | `……` |

---

## 破折号

**`——` 绝对禁止，无例外（含对话）**

> 本条原为「对话中断 `"你——"` → 保留」，与 `writer-rules.md` 铁律 8「完全禁止，无例外」
> 和检测脚本 R2（全文零容忍）冲突，2026-09-23 统一为**全禁**。
> 理由：脚本按全禁扫描，若此处留例外，`"你——"` 会持续被报成 P0 假阳性，子代理无所适从。

| 场景 | 处理 |
|------|------|
| 叙事解释 | → 逗号 `，` |
| 叙事延续 | → 句号 `。` 或逗号 |
| 语气中断 | → 删除 |
| 对话中断 `"你——"` | → 省略号 `……` |
| 对话语气中断 | → 冒号 `：` |

---

## 冒号

- 不单独成段
- 对话中语气中断/断续 → 用冒号

## 代词

**⚠️ 角色名与性别以 `settings/设定.md` 为唯一真源（SSOT）。下表仅为格式示例，新书必须替换为本书真实角色，禁止照抄。**

| 角色 | 代词 | 备注 |
|------|------|------|
| {男主} | 他 | 以设定.md为准 |
| {女主} | 她 | 以设定.md为准 |
| {配角} | 她/他 | 以设定.md为准 |

> 本表原先预填「勋空/林昭/林玥」等实战书里的名字，与 `writer-rules.md` 的 SSOT 铁律冲突
> （实战教训：模板预填名 + 设定"待命名" + 正文实名三层打架 → 50+ 处混用 P0）。
> 2026-09-23 改为占位符，与 writer-rules 一致。

**检查方法**（把 `{女主名}` 换成设定.md 里的真实名）：
```bash
grep -n "{女主名}.*他[^们人方的]" drafts/volXX/ch*_draft.md
```

## 章节标题

格式：`# 第XXX章：标题`

- XXX为三位数字（001, 016, 100）
- 标题不能为空
- 标题全书唯一（不重复）
- 不用破折号、英文标点

---

## 段落

- 双换行分段（网文平台标准）
- 每段不宜过长（手机阅读）
- 不写【本章完】

---

## 字数计算

```bash
# 去除空白后计算字节数，除以3估算中文字数
cat file.md | sed 's/[[:space:]]//g' | wc -c
```
