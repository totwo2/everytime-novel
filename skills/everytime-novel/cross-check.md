# cross-check.md — 跨卷交叉对比方法

> Main读这个文件。每卷完成后或全书完成后执行。

---

## 什么时候做

- 每卷完成后（建议）
- 全书完成后（必须）
- 大规模重写后（必须）

---

## 第一步：生成辅助表单

每卷一个子代理，逐章提取：

| 字段 | 说明 |
|------|------|
| 章节 | chXXX |
| 标题 | 章节标题 |
| 主要角色 | 出场角色（逗号分隔） |
| 场景 | 发生地点 |
| 时间线 | 故事内时间 |
| 核心事件 | 一句话概括 |
| 伏笔/钩子 | 埋设或回收的伏笔 |
| 字数 | 中文字数 |
| 备注 | 问题/矛盾/缺失 |

输出：`reports/table_volXX.md`

### 子代理 Prompt

```
你是数据整理员，为 volXX（ch起-ch止）建立辅助表单。

逐章读取 {路径}/drafts/volXX/ch起_draft.md 到 ch止_draft.md，
提取：章节、标题、主要角色、场景、时间线、核心事件、伏笔/钩子、字数、备注。

写到 {路径}/reports/table_volXX.md

角色名与代词一律以 {路径}/settings/设定.md 为唯一真源（SSOT），从设定.md读取真实角色名，不要照抄任何示例名。
```

---

## 第二步：跨卷对比

读取5份表单，对比以下维度：

### 角色出场频次
- 每个角色在每卷出场多少章
- 有无突然消失/突然出现的角色
- 出场趋势是否合理

### 伏笔追踪
- 哪些伏笔已回收（在哪卷哪章）
- 哪些伏笔未回收（悬而未决）
- 跨卷伏笔是否连贯

### 命名一致性
- 同一角色在不同卷是否用不同名字
- 同一概念在不同卷是否用不同术语
- 检查：同一角色的废弃名/正式名是否混用（示例：某书曾出现"勋璇/林玥""周衡/赵衡"两组混用，具体名以设定.md为准）

### 时间线
- 卷间衔接是否连贯
- 有无时间跳跃或矛盾

### 字数分布
- 各卷平均字数
- 有无异常短章/长章

---

## 第三步：输出报告

```markdown
# 全书跨卷交叉对比报告

## 角色出场频次跨卷对比
| 角色 | vol02 | vol03 | vol04 | vol05 | vol06 |

## 伏笔追踪
| 伏笔 | 埋设卷 | 回收卷 | 状态 |

## 命名一致性
| 问题 | 涉及卷 | 状态 |

## 字数分布
| 卷 | 章数 | 总字数 | 平均字数 |

## 待修复/确认事项
P1/P2列表
```

输出：`reports/cross_volume_analysis.md`
