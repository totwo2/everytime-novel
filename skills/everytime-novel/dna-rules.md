# dna-rules.md — 本书风格 DNA 蒸馏（网文版）

> 主代理读这个文件。目标：把目标风格固化成一份可读取、可复用的产物 `settings/本书语言DNA.md`，
> 让写手每章动笔前必读，解决"换书不换风格、每本都一个味"的问题。
>
> **与去AI味的关系**：DNA 解决"像不像这本书"，去AI味解决"像不像机器写的"。
> 两道工序先后执行：读 DNA → 写 → 去AI味。

## 定位：可选项，不是必做流程

本文件是**可选模块**。触发方式只有两种：

1. **设定阶段问一次**（见 `outline-rules.md` 可选设定项）——用户选 A/B 才走本流程
2. **用户中途主动要求**——"蒸个风格""定一下语言 DNA""照着这本书的味写"

除此之外，任何阶段都**不主动插入、不阻塞流水线**。没有语料、用户不想蒸、或者用户没回应，直接跳过，继续大纲→卷纲→细纲→正文。

**跳过的代价**：写手只能按通用 writer-rules 写，每本书的味会趋同。**硬蒸的代价更大**：没有语料时编出来的 DNA 是幻觉，写手会照着幻觉写，比没有更糟。

---

## 一、定位

`设定.md` 是**内容**的真相文件（角色、技能、规则、伏笔）。
`本书语言DNA.md` 是**写法**的真相文件（句长、对话密度、节奏、语气）。

两者同级，都放 `settings/`。写手两个都要读。

---

## 二、什么时候蒸馏

| 时机 | 语料 | 用途 |
|---|---|---|
| 新书开写前，有对标作品 | 对标作品的**免费章** ≥20 章 | 定这本书要写成什么味 |
| 已写到 20 章以上 | **自己写的**章 ≥20 章 | 校准风格漂移，后半本对齐前半本 |
| 换卷/换阶段 | 本卷已写章 | 防止长书后期风格漂掉 |

**没有语料就不蒸馏**，不要凭"我觉得这本书应该是XX风格"编一份。编出来的 DNA 是幻觉，比没有更糟。

---

## 二·补、DNA 的可移植性：跨类型怎么用

**类型不同，指纹不同——这个判断是对的。** 玄幻、近代、科幻的用词、场景、节奏、爽点密度都不一样。但"整份 DNA 沿用/不沿用"是个太粗的切法，要按层分：

| 层 | 内容 | 跨类型可移植性 | 为什么 |
|---|---|---|---|
| **L1 表层语言** | 句长、对话占比、标点习惯、语气词、人称、常用搭配 | **高** | 这是**作者手感**，跨类型基本稳定——同一作者写玄幻和写科幻，句子长短和对话密度是同一只手 |
| **L2 章节结构** | 开场/收尾习惯、章内节奏 | **中** | 开场收尾习惯稳定；**爽点密度随类型变**（升级流的章内爽点比近代文密） |
| **L3 叙事习惯** | 主角行为逻辑、冲突处理、金手指节奏 | **低** | 强类型相关，跨类型基本不通用，必须重蒸 |

一句话：**手感能带走，套路带不走。**

### 复用检查（开写前必做，别默默沿用）

蒸馏时产物头部必须写**体裁标签**。使用时（主代理派写手前 / 写手动笔前）做一次比对：

| 比对结果 | 动作 |
|---|---|
| **同体裁**（玄幻→玄幻） | 直接沿用，**不打扰用户** |
| **同大类不同小类**（升级流→种田流） | 提一句"检测到已有 X 体裁的 DNA"，**默认沿用 L1+L2**，L3 仅供参考 |
| **跨大类**（玄幻 / 近代 / 科幻 之间） | **必须问用户**，不许默默沿用 |

跨大类的问法：

```
检测到已有《{旧书名}》的语言 DNA（体裁：{旧体裁}），
本次这本是{新体裁}。要怎么用？

A) 只沿用 L1+L2（推荐）→ 保住你的手感（句长/对话密度/标点习惯），
   放掉类型相关的叙事习惯
B) 整体沿用 → 手感+套路都带过来，接受类型特征错配
C) 重新蒸馏 → 有新语料时选这个（拿旧 DNA 当对照基准，看漂在哪）
```

**为什么不许默默沿用**：跨类型沿用 L3 会让新书带着旧书的套路跑（玄幻的金手指节奏套到近代文上，读者会觉得别扭），而这种错配**很难在事后归因**——看起来只是"这本写得怪"。

## 三、语料要求（硬约束）

1. **至少 20 章完整正文**，放 `dna-corpus/`（.md 或 .txt）
2. **必须是人类写的章**。⚠️ **用 AI 生成的稿子蒸馏 = 把 AI 味固化成风格**，这是本流程最容易踩的坑，且踩了很难发现——蒸馏产物会理直气壮地写着"本书偏好破折号"，然后写手照着写满屏破折号。
3. 同一体裁、同一阶段（不要把都市和玄幻混在一起蒸馏）
4. 剔除章节标题、系统面板、作者的话等非正文内容

## 四、蒸馏三层（网文版，砍掉了不适用于虚构叙事的层）

### L1 表层语言（脚本自动统计）
```bash
python3 scripts/distill_dna.py dna-corpus/ --report settings/本书语言DNA-L1.md
```
统计项：
- 句长分布：平均句长、短句（≤15字）占比、长句（≥50字）占比
- **对话占比**：对话字符数 / 总字符数（网文最关键的一项，直接决定"味"）
- 段落节奏：平均段落字数、平均段落句数
- 标点习惯：省略号、破折号、引号、感叹号、问号的每千字频次
- 语气词频次：啊/吧/呢/嘛/哦/嗯/哎/嘿
- 人称与视角：第一/第三人称、视角切换频率
- 高频实词 Top 30

### L2 章节结构（脚本部分统计 + 子代理归纳）
- 开头类型分布：动作开场 / 对话开场 / 场景开场 / 其他
- 结尾类型分布：动作收尾 / 对话收尾 / 悬念收尾 / 情绪收尾
- 转折点位置：章内第几段出现第一个转折
- **爽点密度**：细纲事件数 vs 正文实际事件数（与稽核维度 18「注水章」同一口径）
- 对话/叙述比（与 L1 对话占比交叉验证）

### L3 叙事习惯（子代理深度归纳，脚本不做）
按以下提纲写进产物，每条都要能举出章节号作证：
1. **主角行为逻辑**：遇到问题先做什么？主动还是被动？
2. **冲突处理偏好**：正面硬刚 / 迂回 / 借力 / 回避？
3. **金手指节奏**：多久用一次？用了之后是否付代价？
4. **情绪曲线**：一章内的情绪起伏是几次？低谷怎么过渡？
5. **配角功能**：配角是推进剧情还是提供情绪价值？
6. **信息释放习惯**：什么时候让读者知道什么？藏多少？

## 五、产物规范

`settings/本书语言DNA.md`，结构固定：

```markdown
# 《书名》语言 DNA

> 蒸馏来源：{语料说明，共 N 章} · 蒸馏日期：{日期}
> **体裁：{玄幻-升级流 / 近代-年代文 / 科幻-硬科幻 / …}**
> 适用范围：本 DNA 的 L3 强绑定上述体裁；跨大类复用前先做第二节的复用检查
> ⚠️ 已过 AI 味校验，标记为「待人工确认」的条目不作为豁免依据

## L1 表层语言
（脚本产物，直接贴统计表）

## L2 章节结构
（脚本统计 + 子代理归纳）

## L3 叙事习惯
（子代理归纳，每条附章节号）

## 硬性约束（写手必守）
- 对话占比 {X}%（±5%）
- 平均句长 {X} 字（±3 字）
- 章首类型：{动作/对话}（出现频率 {X}%）
- 章尾类型：{动作}（出现频率 {X}%）
- 禁用/慎用：{本书特有的忌讳}
```

**字数控制在 3000 字以内**。超了就是没蒸馏干净，写手不会读完。

## 六、防固化闸门（必做）

产物生成后，对语料跑一次去 AI 味检测：

```bash
python3 scripts/check_ai_tone.py dna-corpus/
```

判定：
- R1/R2 非零 → **语料本身有 AI 味**，产物中所有相关的语言特征标记为「待人工确认」
- R5/R6/R7/R12 超阈值 → 对应特征（顿号罗列/句同构/段首零回指/翻译腔）标记为「待人工确认」
- 标记项**不作为**去 AI 味的豁免依据，写手仍按通用规则处理

---

## 七、写手必读机制

蒸馏完成后，把下面这条加进写手 prompt（或让写手每次读 `dna-rules.md` 时自动执行）：

1. 读 `settings/设定.md`（内容真相）
2. **读 `settings/本书语言DNA.md`（写法真相）**
3. 从 `dna-corpus/` 挑 **3 章**与本章情境最接近的原文通读（不是找素材，是校准语感）
4. 按 DNA 的硬性约束写本章

> 只读 DNA 整合文档不够——就像 writing-dna 原 skill 强调的：整合文档是压缩后的结论，
> 句子的实际呼吸感只存在于原文里。

---

## 八、冲突优先级

三者打架时按此顺序取舍：

1. **用户本次的明确指令**（要写什么、多长、什么平台）
2. **本书语言 DNA**（这本书的真实写法）——但「待人工确认」条目不在此列
3. **通用去 AI 味规则**（R1–R14）
4. **通用写作规则**（writer-rules 的字数下限、章首章尾铁律）

⚠️ 第 4 条中的**硬性铁律**（字数下限、章首必须是动作或对话、破折号零容忍）**不被 DNA 覆盖**。
DNA 只覆盖"怎么写得更好"，不覆盖"会不会被判不合格"。

## 九、常见坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| 拿 AI 写的稿子蒸馏 | AI 味固化成风格，越写越 AI | 第六节闸门，必跑 |
| 语料跨体裁混蒸 | 产物自相矛盾，写手无所适从 | 一次只蒸一个体裁 |
| 语料 <20 章 | 统计不稳，句长分布失真 | 不够 20 章就不蒸 |
| 产物写太长 | 写手读不完，等于没有 | 硬上限 3000 字 |
| 只蒸一次不管了 | 长书后期照样漂 | 每卷结束重蒸一次，比对漂移 |
